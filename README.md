# EventHub — College-compatible edition

This project uses the **same Gradle and Android build configuration as the supplied Lab3CampusG project**:

- Android Gradle Plugin: 9.4.1
- Gradle wrapper: 9.6.0 (wrapper JAR included)
- Kotlin Compose plugin: 2.2.10
- Compile/target SDK: 37
- Compose BOM: 2026.02.01
- Java source/target compatibility: 11 (this does NOT determine the Gradle runtime JDK)

Open this directory in Android Studio and use the **same Gradle JDK** that successfully builds Lab3CampusG.  Build and run on a college PC before the exam.

Screens: Home, Events, Event Details, My Bookings, Profile. No Navigation Compose, Room, or ViewModels yet.
